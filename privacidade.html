Política de Privacidade

Última atualização: agosto de 2026

O que é o Timãodle

Timãodle é um projeto de fã, sem qualquer vínculo oficial com o Sport Club Corinthians Paulista. Esta política explica de forma simples e honesta como o site lida com dados ao ser usado.

Dados que coletamos

O Timãodle não possui servidor de backend, banco de dados de usuários nem sistema de login. Não coletamos nome, e-mail, localização ou qualquer dado pessoal.

As únicas informações guardadas são as suas estatísticas de jogo (número de partidas, vitórias e sequência), salvas localmente no seu próprio navegador através do localStorage. Esses dados:

  • Ficam apenas no seu dispositivo — nunca são enviados para nenhum servidor
  • Não são compartilhados com terceiros
  • São apagados automaticamente se você limpar os dados de navegação do site

Serviços de terceiros

O site carrega recursos externos para funcionar corretamente:

  • Google Fonts — para exibir as fontes do site
  • jsDelivr (CDN) — para a biblioteca de animação de confete usada ao acertar o jogador

Esses provedores podem registrar dados técnicos básicos de acesso (como endereço IP) conforme suas próprias políticas de privacidade, fora do nosso controle. Veja mais detalhes na página de Cookies.

Contato
